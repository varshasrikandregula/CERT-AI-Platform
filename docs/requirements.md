\# CERT AI Platform Requirements



\## Objective



Build an AI-assisted CERT platform that:



\- Collects security logs

\- Normalizes logs using OCSF

\- Enriches events

\- Detects threats using rules and ML

\- Correlates alerts into incidents

\- Assists analysts using AI

\- Supports response automation



\---



\## Data Sources



\- Sysmon

\- Zeek

\- Suricata



\---



\## Core Components



1\. Kafka

2\. OCSF Normalizer

3\. Enrichment Engine

4\. Detection Engine

5\. Correlation Engine

6\. Risk Scoring Engine

7\. Incident Manager

8\. AI Triage

9\. AI Investigator

10\. AI Reporter

11\. SOAR Engine



\---



\## Expected Outputs



\- Alerts

\- Incidents

\- Risk Scores

\- Investigation Reports
